# Contributing to Aslal Digital Solutions

## Branches

- `main`: production-ready code.
- `develop`: integration branch when we introduce one.
- `feature/*`: individual features.
- `fix/*`: bug fixes.

## Before pushing

Run:

```bash
npm run check
```

## Commit examples

```text
feat: add product marketplace
feat: add partner referral tracking
fix: prevent duplicate lead submissions
chore: update dependencies
```

Never commit `.env` files, credentials, bot tokens, database passwords or API keys.
